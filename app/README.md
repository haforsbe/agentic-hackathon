# IT Support Ticketing System Demo

This demo app is a static, client-side IT support ticketing interface.

## Features

- Create tickets with title, description, priority, status, and assigned technician.
- Edit existing tickets.
- Close tickets in one click.
- Responsive layout for desktop and mobile.
- Semantic HTML and accessibility basics (labels, skip link, focus states, ARIA live regions).

## Files

- `index.html`: semantic structure and UI markup.
- `styles.css`: modern responsive styling.
- `script.js`: ticket data, rendering, and interactions.

## Run on localhost

From the repository root, run one of the following:

### Option 1: Python

```bash
python3 -m http.server 8080
```

Then open:

```text
http://localhost:8080/app/
```

### Option 2: VS Code Live Server extension

- Open `app/index.html` in VS Code.
- Use "Open with Live Server".
- Your browser opens a localhost URL automatically.
